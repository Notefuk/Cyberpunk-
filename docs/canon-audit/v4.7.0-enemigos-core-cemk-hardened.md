## Se corrigió

- `core-boosterganger`: BODY 4 → 2 y Death Save 4 → 2 (Errata v1.25, Core p.412). Ya estaba así desde v4.3.1; se confirma.
- `core-security-officer`: SP de cabeza y cuerpo 13 → 12, Medium Armorjack (Errata v1.25, Core p.415). Era el pendiente de v4.6.2.
- Ids conservados: `core-boosterganger`. El resto de los ids viejos no correspondía a ninguna ficha canon.

## Porte CEMK (plan 6)

`frontend/src/engine/cemkPort.ts` → `portEnemyToCemk(enemy)`. Reglas, cada una con su página del Rule Book (RB) de CEMK:
- Neuroport para todos y todos hackeables (decisión de Giuliano; RB pp. 15, 35-36).
- Netrunner: Cyberdeck → Cyberdeck Port, alcance 50 m (RB p.16); hasta 3 NET Actions (RB pp. 16-17). En las fichas CEMK nativas gana lo impreso: Enemy Netrunner y Rocky Erikson tienen 2. Quickhacks según el rango de Interface: 1→DV6, 2→DV8, 3→DV10, 4+→DV12 (RB p.25). Los programas RED no se portean.
- Self-ICE: solo si el libro lo trae (Passwalls DV 6/8/10, RB p.36).
- Armas Power/Smart/Tech/Melee (RB p.8). SP contra melee a la mitad, redondeando hacia arriba como el motor (RB p.10).
- HP: las 26 fichas de Core y Hardened cumplen la fórmula 10+5×⌈(BODY+WILL)/2⌉.

## Datos completados desde el Core (no impresos en la ficha)

- ROF y cargador de las armas de Core y Hardened: tablas de armas del Core (melee p.92, a distancia p.94). Cada arma lo indica en sus notas.
- Adam Smasher (CEMK): Seriously Wounded no impreso → HP/2; EMP "-" → 0, con nota.
